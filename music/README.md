## 怎么用

1. 把 `sfx/` 复制到游戏 `assets/sfx/`。
2. 按 `sfx-map.json` 的 `files` 数组随机挑一个变体；`rate` 用于体型区分，`loops` 里的文件循环播放。
3. 把 `credits.md` 的内容放进制作人员名单/关于页。
4. 如果游戏以后收费/放广告，删掉 CC BY-NC 文件（10 条）和 CC BY-SA 的 `capybara_079`，只留 CC0 / CC BY。

## 这次处理了什么

- **裁切**：按报告的入点/出点重新裁切；非全长条目见 `处理报告.md`。
- **备注降噪 4 条**：`fox_033`（去背景）、`fox_035`（降噪+去混响）、`fox_037`（降噪）、`squirrel_048`（降噪）。报告里的降噪开关是 0，我按备注执行。
- **循环 6 条**：`fox_035` 首尾接近静音，可直接循环；`bee_087/089`、`cricket_090/091/093` 保留原 220ms 交叉淡化。
- **响度**：以原筛选包实测值为基准，不强行统一到 −18，避免短促音效被限幅器压扁。

## 已知缺口

- **小鹿 / 狼**：各只剩 1 条，连续触发会重复；建议后续补 2–3 条变体。
- **fox_035**：源录音自带混响，已做谱减去混响 + FFT 降噪，底噪从 −35.0 降到 −44.4 dBFS，但无法完全消除；如果仍嫌回声大，建议换源或用 RX De-reverb。
- **cat_067**：极短、高动态的喵叫，受真峰值限制停在 −24.5 LUFS；这是原包就存在的电平，不是本次处理造成的。
- **待定 3 条**：`bird_009`、`alpaca_019`、`deer_028` 未处理，放在 `pending/`。
