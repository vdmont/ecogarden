# 动物习惯与撤回

- 猫追附近蝴蝶、在干燥开阔处晒太阳；狗间歇跟随羊群；卡皮巴拉亲水并泡水休息，鸟会停在旁边；龙寻找附近高山并蜷身休息。饥饿、火灾、醉酒和抚摸等原有规则优先，习惯字段向后兼容旧存档。
- 底栏最后两项为铲除、撤回；湖泊→森林→山脉按 300/650/1000 生态排序。一次拖动是一笔操作。撤回恢复操作前的完整花园，包括能量、生态时间和该操作之后的进度；只保留最近一步，切关或读档后清除。
- 观察模式单击动物即跟随；左栏动物名录显示种类/数量，点名字轮流跟随该物种，放生一只可撤回。死亡或离岛后停止跟随。
- 岩石与浆果丛可直接替换草；山脉与森林沿用对草的覆盖规则，不覆盖动物和成熟树木。
- 所有教程纸条可关闭并记住；任务说明可重新查看。第四关说明植物、幼虫、草食/食虫动物的共生条件；第五关完整列出持续生态与水、树、山的数量要求。第六关无教程。
- 移除 JSON 导入/导出入口；保留自动保存与六个手动槽。设置偏好不随读档被替换。
- BGM 扩展至 128 拍、约 79 秒一轮，加入分句、休止、节奏变化和伴奏；五种新鸟各有不同拟声，羊驼改为较柔和的高音哼鸣。仍为合成音，不是真实录音。

验证：npm test / npm run build。新测试执行实际撤回函数，确认一整排种子/动物及能量和进度回滚；检查习惯、饥饿优先、山顶可达、草地替换、教程关闭持久化和长音乐结构。
