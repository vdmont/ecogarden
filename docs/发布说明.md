# 发布说明 · ecogarden v0.8（模块化工程）

本仓库是「生态花园 · ecogarden」v0.8 的**模块化工程**版本：代码结构从单文件 `index.html` 拆成了按职责分层的 `src/`。功能等价性已通过逐项源码对照与构建产物逐字节比对确认（详见[本文件第七节](#七验证状态)）；真实浏览器渲染、真机与触屏交互尚未验证。

## 一、怎么跑起来

不需要 `npm install`（本工程没有任何 npm 依赖，Three.js 已随仓库提供）。

| 命令 | 作用 | 地址 |
| --- | --- | --- |
| `npm run dev` | 本地试玩开发入口（服务仓库根，按 `src/` 分层加载模块） | <http://127.0.0.1:8877/> |
| `npm start` | 同上 | <http://127.0.0.1:8877/> |
| `npm run build` | 构建离线单文件版 → `dist/index.html` | — |
| `npm run preview` | 预览构建产物（服务 `dist/`） | <http://127.0.0.1:4173/> |
| `npm test` | 22 项行为检查 + 2 项渲染检查 | — |
| `npm run test:ecology` | 长时种群观察（3 个种子） | — |
| `npm run demo` | 重新生成 `docs/演示花园.json` 演示存档 | — |

Windows 下双击 `开始试玩.cmd` 等同于 `npm run dev`；若机器上没有 Node.js，启动器会先尝试打开 `dist/index.html`，没有构建产物时回退到改造前的单文件基线 `legacy/index.html`，两者都不存在才提示安装 Node.js。

> 说明：v0.8 发布包里的工程自带一个 8878 端口的服务器、发布包根目录另有一个 8877 端口的启动器。合并到本仓库后统一为：**8877 = 开发/试玩入口**，**4173 = 构建产物预览**。

## 二、怎么构建离线版

```bash
npm run build
```

`scripts/build.cjs` 会读取根 `index.html`，把 `src/ui/style.css` 内联为 `<style>`，再按 `scripts/files.json` 的顺序把每个脚本内联为 `<script>`，产出**完全自包含**的 `dist/index.html`（约 728 KB，无任何外部 CDN 请求）。

- 发布离线版只需要这**一个文件**，可以直接作为静态站点首页上传。
- 构建时会用 `new vm.Script()` 检查 `scripts/files.json` 中列出的每个脚本的语法（未列入的文件不会被检查，也不会进产物），并要求 `files.json` 与入口 `index.html` 的清单完全一致：任一条目缺失或多余都会直接报错退出，不会静默产出缺代码的产物。
- `dist/` 已被 `.gitignore` 忽略，不进入版本管理。

## 三、代码结构

`src/` 下是**经典脚本**而不是 ES module，按 `scripts/files.json` 的顺序加载，通过 `globalThis` 命名空间通信：

| 命名空间 | 提供方 |
| --- | --- |
| `GardenText` / `T` | `src/data/text.js` |
| `EcoData` | `src/data/{species,levels,achievements}.js` |
| `Eco` | `src/sim/core.js` |
| `GardenModels` | `src/render/models/*.js` |
| `GardenView` | `src/render/scene.js` |
| `GardenCopy` / `GardenPalette` | `src/data/copy.js` / `palette.js` |

这样 `tests/` 能用 Node `require()` 直接加载同一批源文件跑断言，不需要浏览器、打包器或转译。代价是**新增脚本要同步更新加载清单**：`scripts/files.json` 与根 `index.html` 必须一起改（构建顺序以 `files.json` 为准，两者不一致时构建会直接报错）；如果新文件需要被 Node 检查脚本加载，还要加进 `tests/load.cjs`。

常见改动位置见 [`GitHub协作.md`](GitHub协作.md) 里那张表。

## 四、存档

- 存档键沿用 `emergent-garden-v06`，内部版本号为 `6`；v0.7 单文件版的存档与当前版本同键同版本号，因此在**相同来源**下可以直接继续读取，成就与各岛屿进度都会保留，校验与兼容逻辑在 `src/state/save.js`。
- 校验是**严格**的：版本号不是 `6`、或世界尺寸 / 单元格字段越界的存档会被明确拒绝并报错，而不是被静默清空。不要手工修改存档里的 `version` 字段。
- 浏览器按**来源（origin）**隔离存档：`localhost`、`127.0.0.1`、不同端口、`file://` 各自独立，换地址不会自动互通。跨地址或跨设备转移进度请用游戏内「存档」面板导出 / 导入 JSON。
- `docs/演示花园.json` 是可选的第五关演示存档（湖泊、山地、森林与动物齐备），导入会**替换**当前来源的存档，不是新玩家的默认开局。正式新玩家从第一关开始。

## 五、本版边界

- 已验证桌面浏览器与手机尺寸布局，**未**做 Android 真机 / TapPlay / TapTap PC 客户端认证；本仓库不含 APK 或 Windows 安装器。
- 照片导出已实现，尚未逐一验证所有手机浏览器的下载行为。
- 撤销与 PWA 安装尚未实现，留作后续候选。
- 自然生态是有限资源下的概率模拟，种群会波动，不能保证每种动物永不灭绝。
- 模型与 UI 由 AI 辅助以程序化方式生成（不含 Minecraft / Dwarf Fortress 素材）；平台披露口径见 [`GameJam-双端核对.md`](GameJam-双端核对.md)。

## 七、验证状态

本节数字来自本次模块化改造的独立验证（Node.js v24.19.0，在仓库根直接运行；验证过程记录不随仓库提交）。复核时的关键文件指纹：`index.html` 1,601 B / `C85CDCA4…A7A7`，`scripts/files.json` 782 B / `E2441A15…FCD3`，`src/` 27 文件聚合 `F474B91E…0454`，`legacy/index.html` 与 `dist/index.html` 均 728,426 B / `BDD345…41D40`。

- `node tests/load.cjs` 退出码 0、无输出；`node tests/behavior.cjs` 打印 22 条 `PASS` + `22 behavioral checks passed`；`node tests/render.cjs` 打印 2 条 `PASS`；三者重复运行输出逐字符相同。
- `node tests/ecology.cjs` 输出 3 行 JSON（种子 42 / 2718 / 99173），6000 步末点动物/植被总数为 393/1055、394/1028、403/1032，与 [`验证记录.md`](验证记录.md) 的表格逐格一致。采样输出以 [`docs/population-log.jsonl`](population-log.jsonl)（约 7 KB）随仓库保留，重新运行会覆盖它。
- `node scripts/build.cjs` 打印 `Built offline game 728426 bytes`；产物 `dist/index.html` 的 SHA256 为 `BDD345BBA724F93CD656128835438F77B62A2626B50E05CDF932649219D41D40`，与 `legacy/index.html`、发布包根 `index.html`、发布包 `project/dist/index.html` 一致，全量比较差异字节数为 0，连续 3 次从零构建哈希相同；`src/` 27 个文件与发布包 `project/src/` 逐文件一致。
- 上述构建结论是在**当前**（带清单一致性守卫的）`scripts/build.cjs` 上复核的：删除产物后从零构建 3 次均得到同一哈希，且人为制造「入口少一条 / 多一条 / 文件名不符 / 顺序与 `files.json` 不同 / 引用文件缺失 / 被引用文件有语法错误」六类不一致时，构建都会 **非 0 退出并打印明确错误**，不会静默产出偏离基线的产物。
- 本地 HTTP（`node server.cjs`，8877）：`/`、`/src/ui/style.css`、`/dist/index.html` 与入口引用的全部 27 个 `<script src>` 均返回 200 且 Content-Type 正确；路径穿越与点文件请求（含 `/../package.json`、`/%2e%2e/package.json`、`/.git/config`）全部返回 403，24 例探针 0 失败，所有 200 响应体都等于仓库内文件。
- 边界：以上均为 Node 侧与本地 HTTP 检查，**没有**真实浏览器渲染、真机、触屏手势、音效、照片导出与 `file://` 行为的验证。
