# 第六关新邻居与存档

- 普通动物沿用原 15 种权重；稀有池新增 4 种猫、3 种狗、卡皮巴拉及 5 种鸟。传说池为龙 1%、貔貅 49%、白泽 50%。
- 传说池准确权重：龙 1、貔貅 49、白泽 50，合计 100。只在第六关出现，不改变前五关工具。新增 16 个抚摸成就、3 个相遇成就。
- 新邻居参与食物、寿命与饥饿机制。猫找幼虫/松鼠，狗找兔子，也能吃成熟浆果；新鸟吃幼虫/蜜蜂。稀有物种繁殖冷却 600 步、上限 5，龙 1600 步、上限 2。
- 创造模式从岛外按下拖动旋转，从岛内按下仍连续放置。教程纸条加大，箭头优先指向水边可种植且未被纸条挡住的格子。第六关仍无引导。
- 山体使用分层岩色、高峰积雪；相邻山体在相同高度处连接到格边。
- 音乐为原创五声音阶合成旋律；抚摸播放合成拟声，不是真实动物录音。进入花园后启动，后台暂停，设置可分别关闭音乐与音效。
- 原 emergent-garden-v06 自动存档继续使用，不改变版本号。六个独立手动位使用 ecogarden-manual-1 至 6，以列名+行数组压缩地块字段；读写仍经过原校验器。覆盖与读取有确认，空间不足不会清空原槽位。
- 设置移出存档页，玩法入口移除；偏好另外保存，读取花园不会覆盖当前设备设置。手动位保存在本浏览器，导出 JSON 导出当前花园，备份某个旧位置需先读取再导出。

验证：npm test、npm run build；浏览器检查新手纸条/水边箭头、菜单设置、手动存入和读回；tests/visitors-preview.html 可查看全部新模型并试音。旧存档迁移、水流、地形、防闪烁、模型预算测试均保留。
