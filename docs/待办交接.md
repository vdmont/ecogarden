### 1.2 小物件动态（弹跳/旋转/悬浮 + easing）

- 位置：`src/render/scene.js` 的 `drawAnimals()` / `drawEffects()` / `drawClouds()`。
- 目标：给"小物件"加轻微、有缓动的动态（例：飘浮的成就提示、地上的圆环标记、被摸时的爱心已有上浮；植物风动已有）。
- 要求：幅度小、频率慢、用 `1 - Math.exp(-dt/τ)` 之类的缓动，不要正弦硬摆。
- 验收：真实浏览器连拍两帧，物件位置有细微变化；低画质（`view.setQuality('low')`）下不变形。

### 1.3 软阴影微调

- 位置：`src/render/scene.js` 构造器里 `this.sun.shadow` 与 `applyLighting()`。
- 现状：`PCFSoftShadowMap`、1024、`bias=-0.0012`、`normalBias=0.025`，投影范围已随时段收紧（30~44）。
- 可做：高画质时把 `mapSize` 提到 2048；低太阳角度（清晨/黄昏）会出现"影子与物体分离"（peter-panning），调 `bias`/`normalBias`。
- 验收：清晨/黄昏截图里，影子与动物脚底、树根贴合，不飘。

**可行方向**（任选，按成本排序）：

1. **烘进地面颜色**（最省）：在 `draw()` 里，按"某格上站着动物/树/石头"把该格地砖颜色压暗一点（类似 `voxelAO` 的写法），不需要任何透明贴片。

   - 需要一张"当前拍有谁站在哪些格子"的集合，`drawAnimals` 里能顺手收集，`draw()` 在它之前跑 → 用上一帧的集合即可（视觉无感）。
2. **给模型底部加暗块**：模型函数里（`src/render/models/*.js`）在脚底加一个略大的扁平方块，颜色取地面暗色，透明度靠"颜色本身暗"来模拟——不透明，一定画得出来。
3. **离屏后处理**（最重）：手写一个 RenderTarget + 全屏 quad 做屏幕空间遮蔽，但项目零依赖、透明画布、新相纸 UI，成本高，不建议先做。

## 3. 动画工程（动作表已就绪）

先读 `docs/动作表.md`：31 种动物只需 6 套骨架，四足走路一套覆盖 19 种（61%）。

**技术前置（已就绪）**：

- `a.state`（`idle`/`walk`）与 `a.phase`（累计走过的格数，走路相位直接用它，脚不会滑）；
- `src/render/scene.js` 的 `put()` 已支持 `rx`（绕左右轴前后摆，专门给摆腿用）；
- 模型函数签名：`({ a, part, phase, t, i })`，`part(dx,y,dz,w,h,d,color,ry,rz)` 局部坐标。

**任务**：

   - 主要文件：`src/render/models/sheep-alpaca.js`、`fox-wolf.js`、`rabbit.js`、`deer.js`、`squirrel.js`、`boar.js`、`hedgehog.js`、`visitors.js`（按 kind 分支）。
   - 验收：慢速走时脚不滑；停下时腿回到站姿。
2. **鸟/飞虫/甲虫/青蛙/龙**的移动动态（翅膀已有基础扇动）。
3. **习惯动作 1–6**（`a.habit` 已在模拟里算好）：追蝶、晒太阳、跟随、泡水、栖息、盘山——部分在 `visitors.js` 里已有雏形。

## 4. 移轴景深 + 颜色分级（最重，最后做）

- 现状：**零依赖**，没有 `EffectComposer`/`BokehPass`（只有 `vendor/three.min.js`）；画布是透明的，UI 是"相纸"布局。
- 可选路线：
  a. 手写后处理：`WebGLRenderTarget` 渲染场景 → 全屏 quad 做"按屏幕上下或距焦点的模糊"（移轴）→ 回主画布；
  b. CSS 近似：给画布加 `filter`（成本极低但只能整体糊，做不到焦点跟随）；
  c. 只在"高画质"下启用，低画质退回无后处理。
- 要求：景深强度随缩放变化（放大时更浅、全岛视角几乎不糊）；色调分级保持卡通风格，白天/夜晚分别调色，不追求真实曝光。
- 验收：缩放时焦点清晰区域会变化；低画质不崩；性能可接受（用真实浏览器量帧时间，别估）。
