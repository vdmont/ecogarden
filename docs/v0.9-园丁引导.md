# v0.9 园丁引导

- 主界面以“朋友送来一座花园”的设定说明能量、生态值与任务入口。进入花园前不推进模拟。
- 创造模式显示建造工具；观察模式显示镜头与居民操作。观察拖动旋转，双击或触屏双击地块近看；平移按钮、中键、Shift 拖动和双指平移继续可用。
- 前五关有开场说明，最后一关无引导。前两关白框突出工具、箭头指向可放置地块，可从工具栏直接拖到岛上，也可点选后放置。以实际目标指标推进；同一工具指导最多两次成功放置，也可点“知道啦”提前收起，不再常驻。完成记录写入旧存档兼容的新可选字段 tutorial。
- 工具显示每次能量费用；当前能量数字放大。生态值用于第五、六关解锁：湖泊 300、森林 650、山脉 1000，按当前岛屿的累计生态值计算。第六关能量仍无限。
- 中文字体优先采用系统幼圆与手写字体；没有这些字体的平台使用系统后备字体，无在线字体请求。
- 相邻瀑布采用连续满格水幕和统一落差，消除原来的格间空隙；水纹继续运动。
- 火焰覆盖格上的动物会死亡并回归养分。动物寿命缩短，捕食概率从 0.075 提至 0.14 的基础值，饥饿触发门槛从 45 降至 24；繁殖概率与承载量同时降低。

## 验证

22 项既有行为检查、2 组渲染检查通过；新增地形解锁、火灾覆盖所有动物、前两关引导推进和存档记录、寿命检查通过。

桌面与 390×844 浏览器视口验证主界面、工具栏拖放、创造/观察切换、白框箭头与能量显示。手机尺寸检查不替代真机触屏测试。

相同资源场景三组随机种子，各 6000 步（模拟 50 分钟）终点动物数为 150 / 159 / 189，植被为 1024 / 1024 / 1033；旧版同场景为 393 / 394 / 403 只动物。种群仍然会波动，不保证所有物种永远存在。
