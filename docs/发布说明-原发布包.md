# 生态花园 · ecogarden v0.8

> **归档说明（本次模块化改造新增，不修改原文）**：本文件是朋友提供的 v0.8 发布包中的 `阅读我-试玩与发布.md`，原样归档以便对照。
> 其中的路径描述（「发布包根目录的 `index.html` 是完整离线版」「`project/` 目录是完整的模块化工程」）指的是**发布包当时的目录结构**，
> 在现在的仓库布局下已不适用：仓库根 `index.html` 是开发入口，离线成品由 `npm run build` 生成到 `dist/index.html`（不入库），
> 改造前的单文件基线保留在 `legacy/index.html`。当前布局请看 [`发布说明.md`](发布说明.md) 与 [`../README.md`](../README.md)。

一个可以播种、观察、摸摸动物的浮岛生态游戏。六个章节，15 种动物，42 项成就。保留 v0.7 浏览器存档。

## 开始试玩

发布包根目录的 `index.html` 是完整离线版，双击即可打开。推荐双击 `开始试玩.cmd`，然后访问 **http://127.0.0.1:8877/**。需要 Node.js 18 或更新版本；没有 Node.js 时启动器会打开离线网页。HTTP 地址仅本机可用。

`project/` 目录是完整的模块化工程。请先进入 project 目录，再运行以下命令，无需安装依赖：

```sh
npm run dev
# 打开 http://127.0.0.1:8878/
npm test
npm run build
```

构建结果在 `dist/index.html`，自带 Three.js，无外部 CDN。可以把这个文件作为静态网站首页上传到所选托管服务。发布包不是 APK 或 Windows 安装器。

## 你们最常修改的文件

| 文件 | 修改内容 |
| --- | --- |
| `project/src/data/text.js` | 游戏文案与界面文字；搜索中文、修改右侧内容，保留 m001 等键名 |
| `project/src/data/levels.js` | 六关工具、目标、地图配置 |
| `project/src/data/species.js` | 动物放置权重、寿命、食物、繁殖冷却和容量 |
| `project/src/data/achievements.js` | 成就列表与描述引用 |
| `project/src/data/copy.js` | 玩法分阶段开放、图鉴、秘密成就线索 |
| `project/src/data/palette.js` | 植物与动物配色 |
| `project/src/render/models/` | 每种动物模型、植物模型 |
| `project/src/sim/core.js` | 生长、捕食、迁入、繁殖、火与地形 |
| `project/src/state/save.js` | 存档校验及旧版本兼容 |

`scripts/files.json` 决定脚本加载顺序；新增脚本时同时更新工程入口 `index.html`。`vendor/three.min.js` 是第三方库，许可见 THIRD-PARTY-NOTICES.txt。模型由程序绘制，不是外部模型文件。

## 操作

- 点选工具，在岛上按住左键拖动可连续播种、浇水或放动物。
- 滚轮缩放，右键拖动旋转；WASD / 方向键、中键拖动、Shift 拖动或画面箭头可以平移。
- 触屏双指可以平移、缩放与旋转；也可点击“平移”后单指拖动。
- “居民”列出种类和数量；重复点击“找一只”轮流定位同类动物。
- “近距离观察”保持运行。需要停住摸摸时，点暂停或空格。
- 成就通知的“去看看”前往相关位置。没有位置的纯分数成就不会显示定位按钮。
- 关卡页可以重新挑战，保留全局成就及其他岛屿；重建当前关卡前会确认。

## 存档与演示

相同浏览器、相同地址使用原有存档键 `emergent-garden-v06`。`localhost`、`127.0.0.1`、不同端口、离线文件是不同来源，存档不会自动互通；需要在“存档”导出、导入。

`docs/演示花园.json` 是可选第五关演示，包含湖泊、山地、森林和动物；导入会替换该浏览器来源的存档，请先导出自己的进度。它不是默认初始游戏。正式新玩家从第一关开始。

## 本版边界

已验证桌面浏览器和手机尺寸布局，未做 Android 真机 / TapPlay / TapTap PC 客户端认证。自然生态是有限资源下的概率模拟，种群会波动，不能保证每种动物永不灭绝。朋友的原始 16 格模型工程尚未提供，本版是在现有程序模型上增加变体。撤销和 PWA 安装留作后续可选功能。

具体改动和验证见 `docs/反馈落实.md`、`docs/验证记录.md`。GitHub 协作说明见 `docs/GitHub协作.md`。
