# 动物动作表（31 种 → 7 套骨架）

> 目的：在做动画之前先看清"有多少动物、需要多少动作、哪些能复用"。
> 结论先说：**31 种动物只需要 7 套骨架动作**，其中"四足走路"一套就覆盖 **18 种（58%）**。

## 一、现在有多少动物

共 **31 种** = 基础 15 种 + 访客 16 种。

| 骨架组 | 物种数 | 具体物种 | 模型文件 |
| --- | --- | --- | --- |
| **四足** | **18** | 绵羊、羊驼、兔子、小鹿、狐狸、狼、野猪、刺猬、卡皮巴拉、4 种猫（阿比西尼亚/布偶/狸花/橘猫）、3 种狗（边牧/金毛/萨摩耶）、貔貅、白泽 | `sheep-alpaca.js` `fox-wolf.js` `rabbit.js` `deer.js` `boar.js` `hedgehog.js` `visitors.js`（按 kind 分支） |
| **两足（站着）** | **1** | 松鼠 | `squirrel.js` |

## 二、动作清单：每种骨架要几个动作

| 动作 | 触发字段（模拟里已有？） | 一套覆盖 | 现在的状态 |
| --- | --- | --- | --- |
| **走路** | `a.state === 'walk'` + `a.phase`（累计位移） | 全部 31 种 | 相位已就绪，**没有任何摆腿** |
| **待机/呼吸** | `a.state === 'idle'` + 时间相位 | 全部 | 只有一个整体的 sin 起伏（0.014） |
| **吃** | ❌ **没有状态字段**（只能从 `a.full`/`a.hunger` 猜） | 全部 | 无 |
| **睡** | `a.sleep > 0` | 全部 | 只有"整体压扁"（羊/访客有） |
| **被摸** | `a.petUntil` → 心形 | 全部 | 渲染层通用，已做 |
| **幼崽** | `a.age < 0` | 全部 | 整体缩放（0.68–0.72），已做 |
| **醉** | `a.drunk` | 走兽 | 只有羊做了左右倾斜 |
| **被冲走** | `a.drift > 0` | 走兽 | 无专门姿态 |
| **习惯 1：追蝴蝶** | `a.habit === 1` | 猫 | 无（模拟已算好） |
| **习惯 2：晒太阳** | `a.habit === 2` | 猫 | 访客模型里已有"压低"（rest 0.62） |
| **习惯 3：跟随羊群** | `a.habit === 3` | 狗 | 无 |
| **习惯 4：泡水** | `a.habit === 4` | 卡皮巴拉 | 已有"半沉"（rest 0.55） |
| **习惯 5：停在旁边** | `a.habit === 5` | 鸟 | 只有翅膀僵住 |
| **习惯 6：盘山** | `a.habit === 6` | 龙 | **已有盘绕**（六节身体按 sin/cos 铺开） |

**实现数量**：7 组 × 4 个核心动作（走/站/吃/睡）= **28 个**，加 5 个习惯动作 = **33 个**。
但每个"实现"= 在对应模型函数里加几行数字，**不新增文件**；渲染管线不用改（见第四节）。

## 四、技术上已就绪 / 还差什么

**已就绪（不用改渲染管线）**

- `a.phase`：累计走过的格数，**走路相位直接拿它用**（走多远摆多远，脚不滑）
- `a.state`：`idle` / `walk`，动画状态机可以直接读
- 部件坐标是**动物局部坐标**，`part()` 已按朝向旋转
- 整体起伏 `bob`、心形、缩放、倾斜都已存在

**还差（需要你拍板或补一行）**

1. **腿只能倾斜、不能"绕前后轴摆"**：`part(dx,y,dz,w,h,d,col,tilt)` 的 tilt 是绕 Z 轴。
   两条路：**平移摆动**（在模型里把腿的 `dz` 按 `sin(a.phase)` 加减，零管线改动），
   或**给 `part` 加一个绕 X 轴的参数**（改 scene.js 一处，所有模型可选用）。
2. **"吃"没有状态字段**：现在模拟里只有 `full/hunger`，看不出"正在吃"。
   建议加 `a.act = 'eat' | 'walk' | 'idle' | …`（一行字段，存档加白名单）。
3. **鸟的"飞"和"走"没区分**：`move==='fly'` 的 7 种鸟现在也是贴地走；要扑翼就得知道它在飞。
   建议 `a.flying = true`（离地时）或用 `a.state='fly'`。
4. **两个 `phase` 名字太像**：`state.phase`（时间相位，给呼吸/扇翅）和 `a.phase`（位移相位，给走路）。
   建议模型里统一：走路用 `a.phase`，呼吸/扇翅用 `phase`。

## 五、建议的推进顺序（按覆盖率）

1. **四足走路**（18 种，58%）——先做这个，一次吃下大半
2. **鸟走路 + 栖息**（7 种，23%）
3. **通用姿态**：吃、睡、被摸（覆盖全部，但要先补 `a.act`）
4. **习惯动作 1–6**（模拟已经算好了 `a.habit`，只缺渲染）
5. **飞虫 / 甲虫 / 青蛙 / 龙**（5 种，最后补）
